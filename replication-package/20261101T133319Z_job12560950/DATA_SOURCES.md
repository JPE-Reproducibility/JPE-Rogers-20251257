# Data Sources

**Supporting reference; `README.md` governs.** The Data Availability Statement, the
list of included and excluded data, and the data citations all live in `README.md`,
which is the single documentation point for this package. This file is a working
per-source note for a reader who wants more detail on one source than the README
carries; where the two differ, the README is correct. Per-file provenance and
redistribution bases are in `certification/PUBLIC_SOURCE_PROVENANCE.csv`, and
per-variable definitions are in `CODEBOOK.md`.

## Primary Data

### Patent Data
- **Source:** Dimensions patent records and metadata (institutional subscription required)
- **Files:** `all_patents_w_xi_oct22_24.csv` — Patent-level data with quality measures (xi values), firm identifiers, product code assignments
- **Coverage:** All US utility patents matched to FDA product codes, 1976–2023
- **Access status:** Restricted. Exclude individual patent records, metadata, and patent text from the public package unless redistribution rights are confirmed. Public packages may include unrestricted aggregate variables where permitted.

### FDA Product Classification
- **Source:** FDA Product Classification Database + Federal Register notices
- **Files:** `Full_sample.csv` — Product-code-by-year panel with reclassification events, adverse event counts, patent counts
- **Key variables:** `year_reclassified_2_1`, `year_reclassified_3_2`, `FDA_own_accord_3_2`, `controls`, treatment indicators
- **Files:** `RegNum_Factorized_Synth.csv` — Regulation number to product code crosswalk

### Adverse Event Data (MAUDE)
- **Source:** FDA Manufacturer and User Facility Device Experience (MAUDE) database
- **Files:** Various CSVs in MAUDE/ directory
- **Key variables:** L (life-threatening), H (hospitalization), D (death), S (disability) event counts by product code and year

### Reclassification Samples
- **Pre-built control groups:**
  - `intuitive_2_1_oct22_24.csv` — Intuitive controls for II→I
  - `later_treated_2_1_oct22_24.csv` — Later-treated controls for II→I
  - `spillovers_2_1_oct22_24.csv` — Spillover sample for II→I
  - `intuitive_3_2_oct22_24_similarity.csv` — Intuitive controls for III→II
  - `later_treated_3_2_oct22_24.csv` — Later-treated controls for III→II
  - `intuitive_spillovers_3_2_oct22_24.csv` — Spillover sample for III→II

### Safety Patent Classification
- **Files:** `safety_vars_allpats.csv` — Patent-level safety keyword indicators (from word2vec)
- **Robustness variants:**
  - `safety_vars_allpats_updated_v2.csv` — Refined keywords (only "safety")
  - `safety_tagged_patents.csv` — Embedding-distance classification
- **Access status:** Restricted-derived if records are patent-level or if model artifacts are trained on Dimensions-derived patent text.

### Firm Data
- **Source:** CRSP/Compustat via WRDS
- **Files:** `Adverse_fsize_ready_all4_oct22_24.csv` — Firm size (assets) matched to product codes via permno
- **Access status:** Restricted. Exclude raw WRDS/CRSP-Compustat files and firm-level derived files from the public package unless redistribution rights are confirmed.

## Proprietary Data (Not Included)

### MarketScan Claims Data
- **Source:** IBM MarketScan Commercial Claims and Encounters Database
- **Access:** Requires institutional license
- **Files:** `outpatient_combined_censored.csv` (one file; produced from the raw CCAE outpatient tables by `code/00_generate_data/gen_00b_marketscan_extraction.py`, the original extraction program run at NBER)
- **Used for:** Price and utilization analysis (Figure 4, panels (c)-(d); the utilization table rows)
- **Note:** On the public synthetic route this step executes on the synthetic MarketScan
  aggregates supplied by `materialize_simulation.py` and **may not be skipped**: the official
  route permits no transformation skip and must finish with zero skipped steps. If
  `05_price_analysis.py` reports that it is skipping because an input is absent, the inputs
  were not materialized and the run is invalid — it is not an acceptable outcome
- **Public package action:** Exclude raw and derived claims files. Use provider execution, a licensed environment, or clearly labeled synthetic/aggregate substitutes for public code execution.

### LexisNexis Legal Data
- **Used for:** Liability analysis (Appendix Figure D.9)
- **Files:** `data/raw/Liability/**`
- **Access status:** Rights require confirmation before public release. Treat
  vendor exports, derived legal summaries, and hand-coded legal encodings as
  restricted unless redistribution is explicitly permitted. The public package
  excludes the full `data/raw/Liability` data directory.

## Federal Register rules used as data sources

Two shipped inputs are built directly from Federal Register documents. Both rules are cited
here and in the README "Data References"; the underlying text is a U.S. Government work and is
in the public domain.

- **84 FR 71794.** U.S. Food and Drug Administration. "Medical Devices; Exemptions From
  Premarket Notification for Class I and Class II Devices." Final rule, 84 Fed. Reg. 71794
  (December 30, 2019), Vol. 84, No. 249, pp. 71794–71819. Docket Nos. FDA-2017-N-1129 and
  FDA-2017-N-1610; document 2019-27394.
  https://www.federalregister.gov/documents/2019/12/30/2019-27394/medical-devices-exemptions-from-premarket-notification-for-class-i-and-class-ii-devices
  — **File:** `data/raw/Good_2_1_Control_2_1.txt`, a text extraction of the amendatory
  portion of this rule (pages 71797–71819 of the issue, per the running headers inside the
  file). The Class II → I control regulation numbers were read out of this text.

- **82 FR 31976.** U.S. Food and Drug Administration. "Medical Devices; Exemptions From
  Premarket Notification: Class II Devices." Notice of final determination under section 3054
  of the 21st Century Cures Act, 82 Fed. Reg. 31976 (July 11, 2017), Vol. 82,
  pp. 31976–32002. Docket No. FDA-2017-N-1129; document 2017-14453.
  https://www.federalregister.gov/documents/2017/07/11/2017-14453/medical-devices-exemptions-from-premarket-notification-class-ii-devices
  — **Basis of:** `data/raw/Class2_Exemptions_2017_Grennan.csv` (244 product codes across 138
  regulation numbers). This notice is FDA's final determination on the list proposed on
  March 14, 2017 (82 FR 13609). Note that the Cures Act procedure publishes the exemption
  list as a *notice*, not as a rule; the 2019 rule above is what later codified these
  exemptions in 21 CFR.

Three further Federal Register rules — 58 FR 37378, 60 FR 38903 and 63 FR 3142 — are the
reclassification events the paper analyses and are cited in the manuscript bibliography.
