# List of Tables and Figures — and the Programs That Produce Them

**Supporting reference; `README.md` governs.** The authoritative exhibit-to-program
map is the "List of tables and figures" section of `README.md`; this file is the working copy
behind it and is kept in step with it.

Manuscript: `paper/JPE_submission_v8.tex`.
Exhibit **numbers are taken from the compiled manuscript** (verified against the
PDF, not the LaTeX labels). The pipeline produces every script-generated exhibit
below into `output/figures/` and `output/tables/Formatted/`;
`code/audit_pipeline_current.py` (the final step) then confirms each manuscript
exhibit exists. A bare `python3 run_all.py` is **not** the command that does this:
the two safety-measure steps (16 and 17) reuse their precomputed artifacts unless
their flags are passed, so the command that regenerates every exhibit is

```
python3 run_all.py --regenerate-safety-keywords --regenerate-safety-embeddings
```

(plus the route flags documented in `README.md` — `--skip-gen` / `--synthetic-from-raw`
and `--force-estimation` — for the simulated-data routes).

Notes:
- Output files are written to `output/figures/` (`.png`) or
  `output/tables/Formatted/` (`.tex`, `\input` into the manuscript).
- A few exhibits are **author-constructed** (device-type catalogs, one schematic and
  one data-catalog diagram) with no generating script; their data sources are noted.
  Every computational table is program-generated: Tables **D.1**, **D.11** and
  **D.15** are generated by
  `code/10c_generate_appendix_tables.py` and `\input` from
  `output/tables/Formatted/`.
- `{2_1, 3_2}` denotes the Class II→I and Class III→II panels; most event-study
  filenames are built as `<panel>_nolog_<outcome>_oct22_24.png`.
