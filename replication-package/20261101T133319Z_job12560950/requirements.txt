# Direct Python dependencies of the shipped code, pinned to the versions used to
# produce the verified package outputs (Python 3.9.13, macOS x86_64 under Rosetta;
# the same versions are baked into the reference container image).
#
# Every third-party module imported by a shipped .py file is pinned below, at the
# version recorded in requirements-lock.txt. The two exceptions are marked
# "provenance only" at the bottom of this file: they are imported only by scripts
# that document how third-party data were acquired and that the replication does
# not run.
#
# HOW TO INSTALL (this file is the supported install path):
#     /usr/local/bin/python3.9 -m venv ~/fda-env
#     ~/fda-env/bin/python -m pip install --upgrade pip
#     ~/fda-env/bin/python -m pip install -r requirements.txt
#     ~/fda-env/bin/python -m nltk.downloader punkt punkt_tab stopwords wordnet omw-1.4
#
# NOTE ON requirements-lock.txt. That file is the exact transitive freeze of the
# machine that produced the outputs and is kept byte-identical to the copy the
# container image was built from. It CANNOT be installed with a plain
# `pip install -r requirements-lock.txt`: it pins PySimpleGUI==4.47.0, which has
# been withdrawn from PyPI, it pins the Linux/CUDA build of torch, and pip's
# resolver rejects the (self-consistent) set. The container installs it as
#     grep -viE '^(PySimpleGUI|pyreadstat)[=<>]' requirements-lock.txt > reqs.txt
#     python3 -m pip install --no-deps -r reqs.txt
#     python3 -m pip install --no-deps torch==2.2.2 \
#         --index-url https://download.pytorch.org/whl/cpu
# Use the lock file only to look up an exact transitive version; install from
# this file.
#
# The `>=` floors are intentionally omitted here in favor of exact pins so a
# clean-room reviewer reproduces the same numerical results.
#
# R is a separate requirement (rpy2 below is only the bridge). See the README's
# "R packages" section.
