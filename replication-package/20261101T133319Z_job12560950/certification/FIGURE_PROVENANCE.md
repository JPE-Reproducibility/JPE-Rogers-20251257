# Provenance of manually-constructed figures

**Supporting reference; `README.md` governs.**

Every figure in the manuscript is produced by a replication script **except two**
non-scripted schematic diagrams, both documented here per JPE package guidance:
`pic:DeviceDeregulation` (editable draw.io source shipped) and the Data Catalog
diagram `Data_new_latest.png` (a pre-made diagram with no surviving editable source —
see its section below; disclosed per §4.3).

## `output/figures/Deregulation_May31_23_Paper.png` — manuscript Figure 2, label `pic:DeviceDeregulation`

- **What it is:** a schematic/background figure (not a data plot) illustrating the
  FDA's three medical-device risk classes, the approval time/cost associated with
  each, and the Class III→II and Class II→I reclassification policy changes the
  paper studies. It is a conceptual diagram, not the output of any estimation.
- **Construction:** manually drawn in **draw.io / diagrams.net** (an open,
  free diagram editor). It is the only figure not generated by a script.
- **Editable source (shipped):** `manual_figures/Deregulation_May31_23_Paper.drawio`
  — open it at <https://app.diagrams.net> (or the desktop app) to edit; export to
  PNG to regenerate the image. The `.drawio` file is plain XML. It lives in
  `manual_figures/`, beside the PNG `run_all.py` copies into `output/figures/`,
  because it is a package SOURCE asset: `output/` holds only what a run produces
  (and is emptied before a reproduction run), so a source file kept there would
  be destroyed by the clean-run procedure and would count as an unaccounted
  extra in the output comparison. Its SHA-256 is pinned in
  `certification/EXPECTED_MODEL_ARTIFACT_HASHES.csv`.
- **Data/values shown:** the per-class approval **time and cost** figures are
  class averages taken from Makower et al. (2010) (cited in the figure note); the
  device examples (e.g., spinal-fusion devices and full-field digital mammography
  for III→II; hospital beds and ventilator tubing for II→I) are illustrative, drawn
  from the FDA reclassification record. No restricted data is used in this figure.
- **Why it is not script-generated:** it is an explanatory schematic; there is no
  underlying dataset to plot. The editable source above is the reproducible
  artifact.

## `output/figures/Data_new_latest.png` — the Data Catalog diagram (manuscript Fig D.2)

- **What it is:** a manually-created schematic that catalogs the study's data sources and how they link
  (a reference diagram, not a data plot / not the output of any estimation).
- **Construction:** it is a **pre-made image**. `code/11g_descriptive_figures.py` does not *generate* it;
  it only `shutil.copy2`s the existing `data/raw/Data_new_latest.png` into `output/figures/`. So, like
  `pic:DeviceDeregulation`, it is a non-scripted diagram.
- **Editable source:** none survives in the deposit (no `.drawio`/`.svg` master for this image). Disclosed
  here per JPE §4.3: the figure is reproduced by copying the shipped PNG, which is the only artifact that
  remains. It contains no restricted data (a schematic of source names/links only), and the public-data
  format gate verifies the shipped file carries valid PNG magic bytes (it is a real image, not an opaque
  payload).
