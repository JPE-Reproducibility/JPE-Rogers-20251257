# JPE Data and Code Policy — where each requirement is met

**Supporting reference; `README.md` governs.** This file maps the JPE Data and Code Availability Policy
(version v1, 11 September 2026) onto this deposit, one line per requirement, and points at the section of
`README.md` that carries the substance. It adds nothing that `README.md` does not say.

| Policy | Requirement | How this deposit meets it | Where |
|---|---|---|---|
| 1.1 | Data Availability Statement, access terms, cost and time | Every source is listed with its provider, version or vintage, my access date, whether it ships, and the monetary and time cost of obtaining it. | `README.md`, "Data Availability and Provenance Statements" |
| 1.2 | Restricted data: exemption or verification | All four restricted sources are excluded and replaced by a simulated payload that ships, so the code runs end to end without them. Nexis Uni holds a granted exemption. MarketScan, Dimensions and WRDS/CRSP-Compustat are reproduced by an authorized researcher on the real data, and the deposit documents where each file goes and what shape it must have. | `README.md`, "Restricted sources, excluded from the package" and "Where an authorized researcher places the restricted files" |
| 1.3 | Analysis data | Every public and author-created input ships. The restricted analysis files do not; their simulated counterparts do, and `run_all.py` rebuilds the analysis panels from them. | `README.md`, "Analysis data" and "Dataset list" |
| 1.4 | Non-proprietary formats | Every spreadsheet input has a CSV counterpart, and the build refuses to ship a workbook whose CSV twin disagrees with it. | `README.md`, "Dataset list" |
| 1.5 | Codebook and metadata | `CODEBOOK.md` defines the variables of all 108 shipped `data/` members, by name or by an explicit delegation to the FDA's own published record layouts with the columns the code reads. `certification/DATA_DICTIONARY.csv` adds a per-column dictionary over the simulated payload. | `CODEBOOK.md`; `README.md`, "Dataset list" |
| 1.6 | Data citations | Every data source has a citation, including the two Federal Register documents used as data. Every shipped `data/` member has a provenance row in `certification/PUBLIC_SOURCE_PROVENANCE.csv`, which `certification/verify_public_source_provenance.py` checks against the shipped file's hash. | `README.md`, "Data citations" |
| 2.1 | Data-generation programs | Every transformation ships, including the acquisition programs. The MarketScan claims-aggregation program (`code/00_generate_data/gen_00b_marketscan_extraction.py`) is the original program run at NBER, recovered by NBER IT on 2026-10-06 and deposited verbatim; it is not invoked by `run_all.py` because the raw claims do not leave NBER, where the provider can execute it. | `README.md`, "Restricted sources, excluded from the package"; `certification/GEN_PROGRAM_AUTHENTICITY.md` |
| 2.2 | Analysis programs and all outputs | One driver runs the whole pipeline in dependency order. Fixed inventories pin the programs, the outputs and the in-text numbers, and a run that fails to produce any of them fails. The real-data check is a partial check in the sense of this policy, and the README says exactly which steps it takes as given. | `README.md`, "The pipeline: 36 steps", "Instructions to replicators", "Scope of the real-data check" |
| 2.3 | Minimal intervention; environment | Both routes are a single command from the package root. The reference environment is one container image pinned by hash, with the recipe, the pinned Python requirements and the in-image R library list all shipped. | `README.md`, "Computational requirements" |
| 3.1–3.3 | Surveys, experiments, IRB, pre-registration | Not applicable. This is an observational study of administrative and public-source records: no survey instrument, no experiment, no data collected from human subjects, and therefore no IRB approval or consent procedure to deposit. The study is not pre-registered. | `README.md`, "Human subjects" and "Pre-registration" |
| 3.4 | README | `README.md` is the single documentation point: the Data Availability Statement, the contents, the software and hardware requirements, the exact commands for both routes, the acceptance criterion for each, the exhibit map and the data citations. | `README.md` |
| 4.1 | Repository and preservation | The deposit is delivered to the journal's repository, and I commit to preserving the restricted-data documentation and the code for at least five years and to answering questions about them. | `README.md`, "Preservation and assistance commitment" |
| 4.2 | Licence and rights | `LICENSE.txt` grants use of every deposited file for research, teaching, replication and review. Each of the 1001 members of `certification/PUBLIC_PACKAGE_ALLOWLIST.txt` has a row in `certification/DEPOSITED_FILE_RIGHTS.csv` recording the basis on which it may be redistributed, and `certification/gen_deposited_file_rights.py` fails if any member lacks one. | `LICENSE.txt`; `README.md`, "Statement about Rights" and "License for Data and Code" |
| 4.3 | Omissions and unverified results | The README states what is not reproduced and why: the restricted sources, the MarketScan acquisition step that runs only at NBER, the results the simulated route does not check, and the six non-scripted concordance-accuracy figures; all 117 inventoried in-text numbers agree with the manuscript (see the README section "How the manuscript and the package were brought into agreement"). | `README.md`, "Scope of the real-data check", "Scope of the simulated-data check", "How the manuscript and the package were brought into agreement" |

## Two items that await a decision outside this package

1. **The Data Editor's technical acceptances.** The simulated payload's row counts are approximations — two significant figures, set one rounding step above the nearest two-significant-figure value, so the real extract is smaller by half a step to one and a half steps — rather than copied from the restricted extracts, and the delivery (a 4.6 GB archive that unpacks to
   about 22 GB, plus the 5.4 GB reference image) is of the size at which the policy asks for an agreed
   delivery method. Both are matters for the Data Editor to accept or to ask me to change.
Nothing else in this deposit is conditional on an outside decision. The MarketScan
claims-aggregation program is deposited as
`code/00_generate_data/gen_00b_marketscan_extraction.py`.
